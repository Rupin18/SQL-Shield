Vulnerable Query Example

Unsafe SQL string concatenation

⚠ UNSAFE 
query = "SELECT * FROM users WHERE username = '" + username + "'"
cursor.execute(query)

User input is directly combined with SQL syntax. This can allow malicious input to alter the query.

Secure Query Example

Parameterized SQL statement

✓ SECURE 
query = "SELECT * FROM users WHERE username = %s"
cursor.execute(query, (username,))

The database driver treats the supplied username as data rather than executable SQL syntax.
